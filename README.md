# Programação Orientada a Objetos (POO) em Java

Este repositório é dedicado ao estudo e à aplicação dos pilares da **Programação Orientada a Objetos (POO)** utilizando Java, como parte do meu aprendizado prático no curso de Análise e Desenvolvimento de Sistemas (ADS).

O objetivo aqui é transicionar do paradigma estruturado para o paradigma orientado a objetos, aplicando boas práticas de modelagem de software.

---

### **Conceitos e Tópicos Aplicados**

* **Abstração:** Representação de entidades do mundo real em modelos de código focados nas características essenciais.
* **Classes e Objetos:** Criação de moldes (classes) e instanciação de estruturas na memória (objetos).
* **Métodos Construtores:** Inicialização e definição do estado inicial dos objetos no momento de sua criação.
* **Uso da palavra-chave `this`:** Referência aos atributos da própria instância, evitando ambiguidade com parâmetros locais.

---

### **Tecnologias e Ferramentas**

* **Linguagem:** Java (JDK)
* **Controle de Versão:** Git e GitHub
